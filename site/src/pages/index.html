The idea

Four ideas, one pipeline

1 · Many writers

A few leaks don't leak the paper.

Many setters write a few questions each. A program draws the paper at the last moment.

 2 · Sealed

No one can open it alone.

The paper is encrypted. The key is split into five pieces. It takes three.

 3 · Traceable

Every copy is different.

If a photo leaks, the order of questions points to a seat.

 4 · Verifiable

Nothing changes quietly.

Every action is logged in a way that shows if it is edited.
