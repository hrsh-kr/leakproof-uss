# T3: input validation, injection and fault injection (round 5)

Method: copy of the snapshot, run on ports 8830-8835 with temp data dirs, scripts in the scratchpad `t3/` (raw.py, j1-j4.mjs, lock.mjs, fi.sh, jsd/xss.mjs). Low volume throughout. All servers killed. Node used locally was v25.0.0 (VM is 22.x), so Node-internal behaviour (F1, F2) is "confirmed on v25, unverified on 22".

## Verdict
No crash, hang, injection or XSS found. The app is robust at the points the course lectures target. Findings are low severity; the three worth fixing before 17 Nov are F1/F2 (security headers missing on Node-generated replies, contradicts the SR11 claim), F3 (SQLite busy gives 500), F4 (Kelvin-sign username folding).

## Checked and clean (evidence)
- Malformed targets: `//a:b` 400; `/%`, `/%00`, `/%ff`, `*`, `\x` serve the SPA shell (200, no disk access); `/..;/` and `/.env`, `/x.map`, `/Index.HTML` 404; absolute-form `http://evil.com/api/me` 401 (path used, host ignored); 9000-byte target or header 431 with headers; 900 cookies 431; 7 KB cookie 401; undecodable cookie ignored. `CONNECT` closes with no reply (Node default), `TRACE`/`OPTIONS *` 404.
- Smuggling: duplicate and conflicting `Content-Length` 400, `CL+TE` 400, `TE: xchunked` 400, bare LF 400, obs-fold 400, CR/NUL in header 400, CL.0 pipelining answered as two separate responses (400 then 200), pipelined x3 fine. Chunked body over 16 KB 413; `Expect: 100-continue` with huge CL gives 100 then 413. HTTP/1.0 works. Duplicate `Origin` 403, `Origin: null` 403, foreign Origin 403.
- JSON: arrays, strings, null, BOM, 5000-deep nesting (400, no stack overflow), duplicate keys (last wins), `__proto__` and `constructor` keys (stored, no pollution: later requests unaffected), NaN/Infinity/1e21/1e999/negative/float/hex/Arabic-digit strings for topic, correct, seat, slot, seats all 400/404. `topic:"0"` and `correct:"1"` strings are accepted by design (`int()`).
- Injection: SQL strings in username, recovery, head, every path id and seat -> 404/401/400, no SQL error ever surfaced; all queries use `?`. Route params must match `^[0-9a-f]{32}$|^\d{1,4}$`.
- XSS (jsdom executing the real `public/app.js` against a live server, payload `"><img src=x onerror=...><svg onload=...><script>...` in display name, question text, options, plus `javascript:` and `<b>` options): pages `#/`, `#/exam/<id>`, `/questions`, `/cards`, `#/log/<id>`, and crafted hashes (`#//evil.com`, `#/javascript:alert(1)`, `#/exam/<id>/<img...>`) produced `window.__pwn` undefined and zero script/img/svg/iframe/javascript: nodes; the text appears as text. Static grep: no `innerHTML`, `insertAdjacent`, `document.write`, `eval`; only sinks are `window.open('#/...', 'noopener')` (hash only), a Blob `download` link, and `setAttribute` with fixed keys. No open redirect: all routes are hash-only. CSP blocks inline script/style and `object`/`base`; no inline `style` use in app.js.
- Slow clients: slowloris headers 408 at 10.1 s; slow body 408 at 15.1 s; idle connect 408 at 10.1 s; keep-alive closed at 6 s; 45 idle sockets from one address: 31 stayed open, the rest cut by the per-IP cap (40) minus those already closed.
- Cost: trace with 8000 chars of whitespace, newlines, numbering or NUL: at most 15 ms; real copy trace 6 ms; 60 copies (all layouts) 51 ms. Regex audit (all 14 patterns in src, app.mjs, app.js): all anchored and linear; `norm` on 8000 chars 0.2-0.8 ms. No ReDoS. Public log reply 22 KB (200-entry cap).
- Key file variants: 64 hex with no newline, LF, CRLF, uppercase accepted; junk suffix, 31 bytes, empty rejected with a clear message; key mode 644 starts (no permission check, low).
- The words check accepts punctuation and case (`HERON, breeze!!`); that is by design.
